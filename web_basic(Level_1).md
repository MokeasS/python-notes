# Вэб основы
## Структура HTML
HTML (HyperText Markup Language - Язык гипертекстовой разметки) - язык разметки, который описывает структуру веб-страницы. Это не язык программирования, а язык описания!

**Структура сайта**
Представим что сайт - это дом, тогда:
*HTML* - это каркас (стены, комнаты, двери)
*CSS* - это отделка (цвет стен, мебель, освещения)
*Javascript* - это электрика и водопровод (все что движется и реагирует на действия)

**Основные понятия HTML**

1. Теги (tags)
Тег -  это команда в угловых скобках ```< >```, которая говорит браузеру, что здесь находится.
```
<p> Параграф текста </p>
<h1> Заголовок текста </h1>
<a href = "https://google.com">Это ссылка< /a>
```
**Структура тега:**
- открывающий тэг:  ```<p>```
- содержимое: параграф текста
- закрывающий тэг: ```</p>``` (с косой чертой)

**!Важно!**

Большинство тегов парные (открывающий + закрывающий).
Но есть одиночные (например, ```<img>```, ```<br>```, ```<input>)``` - они не требуют закрытия. 

2. Атрибуты (atributes)
Атрибуты - дополнительные настройки тега. Они пишутся внутри открывающего тега в формате ```имя = "значение"```.
```
<a href = "https://google.com" target = "_blank" >Ссылка на Google</a>
```
```<a>``` - тег ссылки
```href = "https://google.com"``` - атрибут ```href``` обозначающий адрес ссылки
```target = "_blank"``` - атрибут ```target``` обозначающий открыть в новой вкладке
```Ссылка на Google``` - текст, который видит пользователь


**Основные атрибуты**
Атрибут - Для чего - Пример
```id``` - Уникальный идентификатор элемента на странице - ```id = "login-button"```
```class``` - Групповой идентификатор (может быть у многих элементов) - ```class = "btn btn-primary"```
```href``` - Адрес ссылки - ```href = "https://..."```
```src``` - Путь к изображению/скрипту - ```src = "image.jpg"```
```name``` - Имя поля формы - ```name = "username"```
```type``` - Тип элемента (кнопка, текст, чекбокс) - ```type = "submit"```

3. Вложенность (дерево тегов)
HTML - это дерево. Один тег может содержать другие теги.
```
<div>
  <h1>Заголовок</h1>
  <p>Текст <a href = "#">ссылка</a> внутри параграфа</p>
</div>
```
**Структура HTML-документа**
Каждая HTML-страница имеет стандартную структуру:
```
<!DOCTYPE html>
<html>
<head>
  <meta charset = "UTF-8">
  <title>Заголовок вкладки</title>
</head>
<body>
  <h1>Всем привет!</h1>
  <p>Это мой первый HTML-документ.</p>
</body>
</html>
```
Разбор
Тег - Что означает
```<!DOCTYPE html>``` - говорит браузеру, что это HTML5
```<html>``` - Корневой тег, то есть всё содержимое страницы
```<head>``` - Служебная информация, которая не видна пользователю
```<meta charset="UTF-8">``` - Кодировка, нужна для правильного отображения русских букв
```<title>``` - Заголовок вкладки в браузере
```<body>``` - Видимое содержимое страницы
