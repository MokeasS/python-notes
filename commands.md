## 1.3)Списки(list). Функции и их методы

Списки - набор чисел в одной переменной, у каждого числа свой индекс.
Нумерация начинается с нуля

Nums = [1 число, 2 число, \...]

Важное замечание. В списка могут быть не только данные типа integer, но
и любых других

Nums = [10, True, 6.7, "world", ...]

Функции:

- Append(значение) - добавляет в список дополнительное значение

- Insert(индекс, значение) - добавляет в список доп значение на место
  индекса, а значение которое было на месте этого индекса смещается
  вперёд

- Extend(список[]) - добавляет в конец список

- Sort() - сортирует список в порядке возрастания [4, 1 ,10 ,2] ->
  [1, 2, 4, 10]

- Reverse() - переворачивает местами значения [ 1, 2, 3] -> [3, 2,
  1]

- Pop(индекс элемента) - удаляет элемент по индексу из списка. Если
  ничего не передавать функции то удаляется последний элемент [1, 2, 3,
  4] -> [1,2,3]

- Remove(значение из списка) - удаляет заданное значение из списка

- Clear() - удаляет все значения в списке

- Count(значение из списка) - считает количество заданного значения

- [Len(список) - позволяет узнать длину списка]

- [Переменная = set(список) -- позволяет хранить элементы списка без
  дубликатов]

**Операции списка set**

- add -- добавление значения в список

- remove -- удаляет значение из списка, [если значения нет выводит
  ошибку]!

- Discard -- удаляет значение из списка, [если значение нет ошибку не
  выводит]

**Кортежи (tuple)**

Это те же самые списки только весят меньше и их нельзя изменять

```
# Список (можно менять) 
my_list = [1, 2, 3]
# Кортеж (нельзя менять)
my_tuple = (1, 2, 3)
```

Отличия от списков (lsit)

- нельзя изменять

- скорость (весит меньше в памяти)

- предназначены для данных, которые должны быть защищены от случайного
изменения

- методы ограничены (только: .count / .index и тд)

**Где применяются**

- географические координаты

- Дата и время

- и т.д.

**Распаковка кортежа (Tuple Unpacking)**

```
person = ("Anna", 22 , "Russian") #Tuple - Кортежи
name, age, country = person
print(name) #Anna
print(age) #22
print(country) #Russian
```

**Когда использовать списки, а когда кортежи**

Кортежи -> когда данные не должны изменяться (например, дни недели,
константы, настройки). Это защитит от случайной ошибки и сделает
программу быстрее.

Списки -> когда данные будут меняться (например, список покупок, имена
пользователей, которые добавляются/удаляются).

## 1.7) Работа с файлами

Файл в python помогает сохранять информацию после закрытия программы

В python можно:

1)  Читать файл -- ([r -- read])

2)  Записывать в файл -- ([w -- write, перезаписывает всё])

3)  Добавлять в конце файла -- ([a -- append])

Открытие файла 2 способа

1)  [Базовый]
```
f = open("file.txt", "r")# Открыть файл
content = f.read() # Прочитать
f.close() # ЗАКРЫТЬ (обязательно!)
```
2)  [Современный]
```
with open("file.txt", "r") as f:
    content = f.read()
# Файл автоматически закроется после выхода из блока
```

Лучше всего использовать Современный способ, потому что даже если
произойдет ошибка файл закроется

**Три режима открытия файла**

Режим - Что делает - Если файла нет - Если файл есть
"r" - Чтение - Ошибка [FileNotFoundError] - Читает
"w" - Запись - Создает новый - **Стирает всё** и пишет заново
"a" - Добавление - Создает новый - Дописывает в конец

**Чтение из файлов "r"**

- read() -- прочитать всё сразу
```
with open("file.txt", "r") as f:
    content = f.read()
    print(content) # Весь текст одной строкой
```
- readlines() -- прочитать построчно все строки
```
with open("file.txt", "r") as f:
    lines = f.readlines()
    print(lines) \# [\'Строка 1\n\', \'Строка 2\n\', \'Строка 3\n\']
```
- readline() -- прочитать одну строку
```
with open("file.txt", "r") as f:
    first_line = f.readline()
    print(first_line)
```
- Перебирание строк в цикле
```
with open("file.txt", "r") as f:
    for line in f:
    print(line.strip()) \# .strip() убирает \n в конце
```
**Запись в файл "w"/ "a"**

- write() -- Записать строку
```
with open("file.txt", "w") as f:
    f.write("Привет, мир!\n")
    f.write("Вторая строка\n")
```
!!! write() не добавляет в конце \n автоматически !!!

- writelines() -- Записать несколько строчек
```
lines = ["Строка 1\n", "Строка 2\n", "Строка 3\n"]
with open("file.txt", "w") as f:
    f.writelines(lines)
```
- append() -- Добавить в конец
```
with open("file.txt", "a") as f:
    f.write("Новая строка\n")
```

## 1.8) Обработчик исключений. Конструкция (try - except)

Если в коде появляется ошибка то программа не заканчивает свою работу а
выводит значения после except
```
try:
    user_age = int(input("Введите свой год рождения: "))
    current_year = int(input("Напишите какой сейчас год: "))
    print(current_year - user_age)
except ValueError:
    print("Ошибка, введите число!")
```
**Полная конструкция (try/except/else/finally)**
```
try: # 1. Пытаемся выполнить 
    num = int(input("Введите число: "))
except ValueError: # 2. Если ошибка - обрабатываем
    print("Это не число!")
else: # 3. Если ошибки НЕ было - выполняем 
    print(f"Вы ввели: {num}")
finally: # 4. Выполняется ВСЕГДА (и при ошибке, и без)
    print("Программа завершена.")
```
**Основные типы ошибок**

**Ошибка** - **Когда возникает** - **Пример**
**ValueError** - Неверное значение - int("abc")
**TypeError** - Неверный тип - "5" + 5
**ZeroDivisionError** - Деление на ноль - 10/0
**KeyError** - Ключа нет в словаре - { :"Moscow"}
**IndexError** - Индекс вне списка - Value = [1,2,3], Value[4]
**FileNotFoundError** - Файл не найден - open("log.txt")
**AtributeError** - Нет такого метода - "abc".push()

**Примеры обработки**

- 1 ошибка
```
try:
    num = int(input("Введите число: "))
except ValueError:
    print("Это не число!")
```
- Несколько ошибок
```
try:
    a = int(input("Введите 1-е число: "))
    b = int(input("Введите 2-е число: "))
    print(a / b)
except ValueError:
    print("Это не число!")
except ZeroDivisionError:
    print("На ноль делить нельзя!")
```
- Одна ветка для нескольких ошибок
```
try:
    a = int(input())
    b = int(input())
    print(a / b)
except (ValueError, ZeroDivisionError):
    print("Ошибка ввода или деление на ноль!")
```
- Поймать всё (Exception) -- не стоит использовать постоянно, можно
  пропустить баг и тд
```
try: \# любой код
except Exception as e:
    print(f"Ошибка: {e}")
```
Инструменты

raise -- возможность вызвать свою ошибку
```
def check_age(age):
    if age < 0:
    raise ValueError("Возраст не может быть отрицательным!")
    return age
    try:
        check_age(-5)
    except ValueError as e:
        print(f"Ошибка: {e}") \# Ошибка: Возраст не может быть отрицательным!
```
assert - это «встроенный тест». Если условие ложно --- программа падает
с AssertionError.
```
def divide(a, b):
    assert b != 0, "Делитель не может быть нулём!"
    return a / b
divide(10, 2) \# 5.0
divide(10, 0) \# ❌ AssertionError: Делитель не может быть нулём!
```
